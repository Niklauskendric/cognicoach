# NOTE ON PROVIDERS: Groq's chat API is OpenAI-compatible, so
# langchain-openai talks to Groq by pointing base_url at
# https://api.groq.com/openai/v1 with a GROQ_API_KEY. Whisper
# transcription (Day 14) is a separate API surface with no
# OpenAI-compatible shim, so it uses the native `groq` SDK instead —
# both need to be installed.
#
# NOTE ON EMBEDDINGS: Pinecone (Day 11) uses local sentence-transformers
# embeddings (384-dim), NOT OpenAI embeddings — this project has no
# OpenAI usage anywhere. If you don't have an OPENAI_API_KEY in .env,
# that's correct and expected (guardrails_client.py mirrors your
# GROQ_API_KEY into OPENAI_API_KEY in-process for NeMo only — see
# backend/safety/guardrails_client.py).
